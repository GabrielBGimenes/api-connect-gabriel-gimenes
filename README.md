# API Connect - Gerenciamento de Usuários (MVP)

API RESTful desenvolvida para prover suporte ao MVP de uma plataforma de gerenciamento de usuários.

## 🚀 Tecnologias Utilizadas
* Node.js
* Express

## ⚙️ Passo a Passo para Execução Local
1. Clone o repositório
2. Instale as dependências com `npm install`
3. Inicie com `npm run dev`
